Sonic Bloom

It is a web based visualizer that can capture your device's audio or a audio/video file can be uploaded and it visualizes it.
Got a mic and want to visualize your voice. No problem connect it and we have got you covered.

We offer 5 visual mode ranging from Spectrum, Waveform, Circles, Particles, Aurora.

To use it you need to install this repo and open the index.html file to run it.

Even better, you can add it as a web extension and acess it with any problem.
Just go to chrome://extensions or edge://extensions, and enable developer mode.
Select Load Unpacked and upload this folder.

Enjoy your music!!!!!!!
